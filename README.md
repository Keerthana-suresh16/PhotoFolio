PhotoFolio

An online photo album application built using React and Firebase
Firestore.

Features

- Create albums
- Add images
- Edit images
- Delete images
- Search images
- Image carousel
- Firebase Firestore database
- Loading indicators
- Toast notifications

## Technologies

- React
- JavaScript
- Firebase
- Cloud Firestore
- React Toastify
- React Spinner Material
